# NCSA BHARAT

A comprehensive Cybersecurity & Defense Training Portal featuring interactive training modules, simulated attack environments, certification roadmaps, and full-stack course management.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Framer Motion, React Icons, React Router DOM
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), JWT Authentication, Bcrypt
- **Styling**: Modern cyber-themed UI with custom glassmorphism and animations

---

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- MongoDB (optional for demo / local database)

### 2. Backend Setup
```bash
cd server
npm install
# copy .env.example to .env if needed
node index.js
```
The backend will run on `http://localhost:5000`.

### 3. Frontend Setup
```bash
cd client
npm install
npm run dev
```
The frontend will run on `http://localhost:5173`.
